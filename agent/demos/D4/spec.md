ADC 采集与变化上报演示（D4）：结合宿主输入事件与 ADC 直读。app_init 仅 log "d4 init"。app_evt(int payload)：payload 高 16 位 = 输入实例号、低 16 位 = 新采样毫伏值（十进制手写转换）；每收到一次事件 log "d4 evt inst=<i> mv=<v>"。app_tick（100ms）：调用 int ts_adc_read(int ctx,int inst)（ctx 传 0，宿主注入真值；返回值 >=0 为毫伏、<0 为错误码如实 log 后跳过本拍）；静态变量 last_reported 初值 -1：若 |mv - last_reported| >= 20 或 last_reported < 0，则 log "d4 report mv=<mv> delta=<差值绝对值>" 并更新 last_reported、reports 计数 +1；当 reports >= 8 时 log "D4-DONE reports=8" 一次（静态标志防重）。health_ping 恒返回 0。caps=["adc:read:0"]。约束：十进制数转字符串一律手写循环；确定性输出；源码禁任何 #include。
