滞回控制环演示（D6）：ADC 输入 → 滞回逻辑 → PWM 输出（含限幅演示）。app_init：log "d6 init"；随后调用 int ts_pwm_set(int ctx,int inst,int hz,int permille) 请求 1000Hz 1000‰（inst=1）——通道限幅上限 700‰，预期返回负错误码 -12，log "d6 clamp rc=-12"（限幅实证）。app_evt(int payload)：log "d6 evt mv=<payload 低 16 位>"（十进制手写）。app_tick（100ms）：ts_adc_read(ctx=0, inst=0) 读毫伏 mv（<0 如实 log 跳过）；滞回状态机（静态 state：0=低 1=高）：mv > 82 且 state==0 → state=1、请求 pwm 1000Hz 700‰、log "d6 out mv=<mv> duty=700 rc=<r>"；mv < 76 且 state==1 → state=0、请求 pwm 1000Hz 0‰、log "d6 out mv=<mv> duty=0 rc=<r>"（1000-2000 之间保持不动作）；输出变化计数 changes +1；changes >= 6 时 log "D6-DONE changes=6" 一次。health_ping 恒返回 0。caps=["adc:read:0","pwm:set:1"]。约束：十进制数转字符串一律手写循环；确定性输出；源码禁任何 #include。
