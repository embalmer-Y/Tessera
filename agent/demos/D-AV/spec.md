摄像头帧采集与分片发布演示（D-AV）：使用宿主音视频 natives 完成确定性JPEG 帧传输。app_init 仅 log "dav init"。app_tick（100ms）内按静态状态机推进（file-scope 变量：state/frame_len/chunk_idx/n_chunks/frame_id/frames_sent/total_bytes）：state 0（取帧）：调用 int ts_av_capture(int ctx, char* buf, int cap)（ctx 传 0——宿主注入真值；buf = 38400 字节静态数组），返回值 len：len<0 → log "dav cap-rc=<len>"（十进制手写转换）且停留在 state 0；len>=1 → frame_id 自增、n_chunks=(len+1023)/1024、chunk_idx=0、state=1；state 1（每 tick 恰发一分片）：chunk 长度 = 1024 与 len-chunk_idx*1024 的较小者；调用 int ts_net_publish(int ctx, int frame_id, int chunk_id, int n_chunks, const char* buf, int clen)（buf 指向帧缓冲内偏移 chunk_idx*1024 处）：返回 >=0 → chunk_idx++；返回 -5（BUSY）→ 本 tick 直接 return（下一 tick 重发同分片）；其他负值 → log "dav pub-rc=<rc>"并弃帧回 state 0；chunk_idx==n_chunks → log "dav frame <frame_id> len <len> chunks <n_chunks>"、total_bytes+=len、frames_sent++、若 frames_sent>=10 → log "DAV-DONE frames=10 bytes=<total_bytes>" 且 state=2（此后空操作），否则 state=0。health_ping 恒返回 0。caps=["av:read:0"]；manifest 字段 av_fmt="rgb565"、av_w=160、av_h=120（JPEG 暂不可用：上游 esp32 DVP 驱动对变长帧 bytesused=pitch*height 且 JPEG 官方 pitch=0 → 零长 DMA；登记观察项——RGB565 为 DEC-47② 已裁保底格式）。约束：帧缓冲为 wasm 线性内存内的静态数组；十进制数转字符串一律手写循环（逐位除 10 取余反排）；确定性输出（无随机/墙钟分支）；源码禁任何 #include（宿主零依赖约定——字符串/比较操作一律手写循环，编译器内建可用但标准库头不可用）。
