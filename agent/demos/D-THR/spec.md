双线程计数演示（D-THR，DEC-55/Q-37 A 首个真线程消费者）：使用宿主线程编排 natives 完成一次性 worker 汇合。manifest 字段 threads=2（总并发含主）；caps 为空数组（仅日志——宿主 TEST 语义自动授予 log:write:0；无物理通道）。app_init 仅 log "dtr init"（十进制手写转换）。app_tick（100ms）按静态状态机推进（file-scope 变量 state/h/r）：state 0：调用 int ts_thread_start(int ctx, const char* name, int name_len, int arg)（ctx 传 0——宿主注入真值；name = "count_worker" 字面量、name_len = 13、arg = 2000），返回句柄 h：h < 0 → log "dtr spawn-rc=<h>" 且 state=3；否则 state=1；state 1：调用 int ts_thread_join(int ctx, int handle)（ctx 传 0），返回 r：r != 2000 → log "dtr join-rc=<r>" 且 state=3；否则 state=2；state 2：校验共享计数器 g_cnt == 2000 且 r == 2000 → log "DT DONE cnt=2000 rc=2000" 且 state=3（此后空操作），不匹配 → log "dtr mismatch cnt=<g_cnt>" 且 state=3。count_worker（导出名 count_worker，int count_worker(int n)）：用 __atomic_fetch_add(&g_cnt, 1, __ATOMIC_RELAXED) 循环累加 n 次后返回 n（worker = 一次性任务：入口返回即线程结束；g_cnt 为共享线性内存中的静态 int，主线程与 worker 经共享内存可见）。health_ping 恒返回 0。导出集 = health_ping/app_init/app_tick/count_worker。约束：确定性输出（无随机/墙钟分支——join 后读数序确定）；源码禁任何 #include（宿主零依赖约定——字符串/十进制转换一律手写循环，编译器内建可用但标准库头不可用）；跨线程数据只用原子内建（-pthread 编译档由宿主链注入——源码不写编译指令）。
