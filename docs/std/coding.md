# 编码规范（coding.md）· v0.1 草案

> **状态**：v0.1 草案，随规范套件待 owner review（见 `README.md`）。
> **适用**：firmware/（C，Zephyr）、agent/ 与工具（Python）；wasm APP 源码语言不限（Rust/C 等），仅约束其框架侧接口使用。

## 1. 文件与编码（军规 4）

- 全库文本 UTF-8 无 BOM、换行 LF；`.gitattributes`（`* -text`）保证字节保真——**不得绕过**。
- 批量文本操作（脚本改写/生成文件）必须显式指定编码（如 Python `open(..., encoding='utf-8', newline='\n')`）；禁用依赖系统代码页的工具（前因：旧项目因此损毁 8 份文档）。

## 2. C / Zephyr

- 风格：Zephyr 官方编码规范 + clang-format（配置取自 Zephyr 树，仓库固定一份副本）；CI lint 必过。
- 命名：框架公共符号 `ts_<模块>_<动作>`（如 `ts_safety_commit`、`ts_time_ms`）；新符号先查 `docs/names.md` 碰撞；**禁裸单字母跨文件标识符**（军规 6；局部循环变量除外）。
- 头文件：公共 API 头文件变更 = review 门 ③，先登记 Q。
- 并发：输出路径加锁规则由 ts-safety 统一（调用者不自带锁）；ISR 内禁分配/禁队列/禁协议调用（estop 路径机械检查，testing.md §3.5）。
- 内存：静态/池分配优先；动态堆仅限 WAMR 实例堆（预算固定并显式声明）。
- include 依赖方向：只允许上层引下层（APP→服务→安全→核心→Zephyr）；反向引用 = 架构缺陷（CI 依赖检查可后置到 M1）。

## 3. 确定性编码禁令（合同 9）

- 控制与调理链**禁**：未播种随机、墙钟/RTC 直读（时间一律 `ts_time_ms()` 单调源）、依赖容器/链迭代序的行为。
- 网络接收时间戳等外部时间只作数据记录，不参与控制决策。
- 违反由 L5 禁用模式扫描拦截（testing.md §3.3）；豁免须 Q 登记。

## 4. 常量纪律（军规 2 的代码面）

- 一切可调常量（限值、超时、尺寸、周期）定义处注释必须标注出处：`/* 来源: DEC-xx */`、`/* 来源: Q-xx（待裁初值） */` 或 `/* 来源: 推导 <文档#锚点> */`。
- 无出处魔数 = CI 失败（testing.md §3.4）；"临时值"不存在——要么有出处，要么登记 Q。

## 5. Python（agent/、工具、测试）

- ruff（lint + format）+ 渐进类型标注（公共函数先全覆盖）；CI 必过。
- pytest 测试与实现同批（testing.md §5）。
- 文件IO显式 UTF-8；路径处理用 `pathlib`。

## 6. 注释与文档纪律（军规 3 在代码中的映射）

- 注释只写代码自身表达不了的约束（为什么限这个值、为什么顺序不能换）；**禁**"解释下一行做什么"式注释与变更日志式注释（git 已留痕）。
- 模块级设计说明放 `design/`，代码头只留一行职责描述 + 指针。
