# R13 · 结构件/外壳 3D 打印设计调研 · v0.1

> **本文件是什么**：DEC-68③ 调研单元（owner：「Agent 需能对硬件进行外壳/结构件设计，设计出可直接 3D 打印的结构件」——调研产出，不实施）。多域 DomainPack（DEC-33）**结构件域前哨**。V0.13.0 R13 单元。

## 1. 定性与域边界

结构件域 = **LLM 生成 + 机械 Verifier** 的创作域——与固件创作域（AG3「域无关循环引擎 + CreationVerifier 插件」）精确同构：生成物 = 参数化 CAD 脚本，验证器 = 可打印性/装配约束机械检查。这是 DEC-33「能力以域为单位扩展」的第三个具体域形态（固件 → 板卡验证 BV1 → 结构件）。

## 2. 参数化 CAD 路线对比（调研核心）

| 维度 | OpenSCAD | **CadQuery（倾向）** |
|---|---|---|
| 语言 | 自有 DSL（声明式） | **Python 库**——与本平台生态同构（Agent 面零新运行时） |
| LLM 可生成性 | 语料多，但调试性差 | Python 代码 = 既有 ws_* 工具面/锚点编辑/编译门全部复用 |
| 可验证性 | 需外部渲染比对 | 脚本即模型——参数断言/几何查询 API（体积/包围盒/截面）原生可机械检查 |
| 参数化 | 变量 + module | 真参数对象（sketch → extrude 链），约束修改友好 |
| 风险 | — | 学习语料较薄；几何内核（OCP）依赖重（沙箱安装面） |

**倾向结论**：CadQuery（Python 域内自洽——「零新运行时」纪律延伸）；OpenSCAD 保留为导入参照。执行形态 = 沙箱内 `cq-editor`/headless OCP 渲染 STL → 网格检查器。

## 3. 可打印性约束面（Verifier 检查目录 v0——每条机械可判）

| 检查 | 判据 | 级 |
|---|---|---|
| 壁厚 | 最小壁厚 ≥ 材料下限（PLA 1.2mm/PETG 1.6mm——参数化） | fail |
| 悬垂 | 面片法线与竖直夹角 > 45° 的悬垂面须有支撑或改设计（无支撑模式） | fail |
| 桥接 | 跨度 > 8mm 的桥接结构 → fail（改设计或加支撑模式） | fail |
| 公差 | 配合面间隙 ∈ [0.2, 0.4]mm（FDM 件装配经验窗） | warn |
| 封闭性 | 网格流形闭合（非流形边/孔洞 = 不可切片） | fail |
| 尺寸 | 包围盒 ≤ 打印机行程（参数化 220×220×250 缺省） | fail |
| 薄壁特征 | 尖角/针状特征（切片失败风险） | warn |

全部为**网格级/脚本级机械检查**（trimesh 类库可判）——零 LLM（BV1 确定性纪律同构）。

## 4. 与功能需求的耦合（设计输入面）

- **开孔对位**：接口开孔（USB/串口/SD 槽/按键）位置 = 板卡外形事实——输入 = **板卡画像扩展节**（R12 `[hardware]` 邻接：`[physical]` 外形长宽高/安装孔位/接口坐标——数据手册或实测卡尺录入）；无坐标 = fail-closed（不开孔，宁保守）。
- **散热**：主控功耗（R12 `power_ma`）> 阈值 → 通风窗/风扇位提示（规则化）。
- **装配**：螺柱位置 = 板安装孔镜像；卡扣 vs 螺接 = 参数（材料收缩率联动）。
- **判据派生**：结构域 spec 判据 = 「板可装入/孔位对通/盖板卡扣闭合」——**实物判据门**需人工量具（唯一非机械环节，如实登记）；打印前机械面 = §3 检查目录。

## 5. Verifier 形态（DEC-33 插件同构）

```
StructuralVerifier（域插件）:
  compile  = CadQuery 脚本执行 → STL 网格（沙箱、超时、无网络）
  check    = §3 检查目录逐条（结构化证据——CheckResult 同型）
  package  = STL + 打印参数单（材料/层高/支撑/方向）→ 交付物
  simulate = 切片预览（可选，v2）
```

CreationLoop 主体零改动（生成-验证-修复循环直接复用）——**这是域无关引擎的第三次域应用实证**。

## 6. 缺口与路线（登记不实施）

1. OCP/CadQuery 沙箱依赖重（百 MB 级）——沙箱策略（装宿主 vs 独立 venv）随立项定；
2. `[physical]` 画像节无数据源自动化（卡尺实测 = 人工）——首板（atk 外壳）实作时沉淀；
3. 打印机行程/材料参数 = 项目级配置（非硬编码）；
4. 实物判据（装配验证）= BV1 式「物理判据待 owner」同型——C6 类比，如实登记。
