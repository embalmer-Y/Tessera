Osptek ESP32-P4C5 Core Board
############################

Overview
********
ESP32-P4 (dual-core RISC-V 400MHz) + ESP32-C5HF4 companion (Wi-Fi 6 dual
band + BT5 LE, SDIO interconnect) stamp core board by Osptek (osptek).

- 16 MB NOR flash, 32 MB embedded PSRAM
- CH343 USB-UART bridge on UART0 (GPIO37/38)
- No on-board LED or user buttons (88-pin stamp core)

Adapted from in-tree ``waveshare/esp32p4_wifi6_dev_kit``.
Upstream docs: https://gitee.com/osptek/esp32-p4c5-core-board
